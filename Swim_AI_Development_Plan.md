# Swim AI Development Plan

## Vision

Build an AI-first swimming coaching platform that helps coaches plan,
manage, analyse and improve athlete performance.

## Principles

-   Web-first MVP
-   AI as a separate service
-   Modular monorepo
-   API-first architecture
-   Production-ready from day one

## Tech Stack

-   Next.js (Frontend)
-   NestJS (API)
-   FastAPI (AI)
-   PostgreSQL + Prisma
-   Clerk Authentication
-   Tailwind + shadcn/ui
-   Vercel + Railway

## Phase 1 -- Foundation (Week 1--2)

-   Monorepo
-   Docker
-   CI/CD
-   Authentication
-   Database
-   Shared packages

### Deliverables

-   Login
-   Dashboard shell
-   Database migrations
-   Deployment pipeline

## Phase 2 -- Core Coaching (Week 3--5)

-   Coaches
-   Athletes
-   Teams
-   Workout Builder
-   Templates
-   Calendar

### Deliverables

-   CRUD for all core entities
-   Weekly planner
-   Workout assignment

## Phase 3 -- AI MVP (Week 6--8)

-   Workout generator
-   Workout editor
-   AI chat
-   Session suggestions

## Phase 4 -- Analytics

-   Attendance
-   PB tracking
-   Meet results
-   Training load
-   Readiness

## Phase 5 -- Commercial

-   Stripe
-   Multi-club support
-   Roles & permissions
-   Notifications
-   Mobile planning

## GitHub Milestones

1.  Foundation
2.  Core Platform

## Success Criteria

-   Coach can manage athletes
-   Coach can build and assign sessions
-   AI can generate editable workouts
-   Calendar drives weekly planning
-   Platform supports multiple clubs
